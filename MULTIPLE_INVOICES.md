# Множественные заявки в счетах

## Что изменилось

Теперь один счет может включать несколько заявок от одного клиента. Это позволяет:
- Накопить заявки за период (например, 2 недели)
- Выставить один общий счет на все заявки
- Клиент оплачивает одним платежом все заявки сразу

## Изменения в базе данных

### Схема
- Убрано поле `requestId` из таблицы `invoices`
- Создана промежуточная таблица `invoice_requests` для связи многие-ко-многим
- Миграция автоматически переносит существующие связи

### Миграция
Файл: `apps/api/prisma/migrations/add_invoice_requests_table.sql`

Для применения миграции на сервере:
```bash
cd apps/api
# Выполнить SQL миграцию вручную или через Prisma
psql -d mini_crm -f prisma/migrations/add_invoice_requests_table.sql
```

## API изменения

### POST /admin/invoices
Теперь принимает массив `requestIds` вместо одного `requestId`:

```json
{
  "number": "СЧ-001",
  "counterpartyId": 1,
  "requestIds": [10, 15, 20],
  "items": [...]
}
```

### Ответы API
Все endpoints теперь возвращают счета с массивом `requests`:

```json
{
  "id": 1,
  "number": "СЧ-001",
  "requests": [
    {
      "id": 1,
      "invoiceId": 1,
      "requestId": 10,
      "request": { ... }
    }
  ]
}
```

## UI изменения

### Страница "Счета/Акты"
- Колонка "Заявка" переименована в "Заявки"
- Отображаются все связанные заявки через запятую: "#10, #15, #20"
